# 06 — Lantai Desain Berbasis Bukti (berlaku semua deck, kecuali override tercatat)

| Aturan lantai | Dasar |
|---|---|
| Judul slide = kalimat pernyataan (assertion), bukan frasa topik | Garner & Alley 2013, *IJEE* 29(6):1564-1579, p<.01 |
| Isi slide = bukti visual, bukan dinding bullet | struktur assertion-evidence (Alley, Penn State) |
| Buang materi tak mendukung pesan (coherence) | Mayer |
| Teks slide ≠ transkrip; naskah masuk speaker notes (redundancy) | Mayer |
| Satu pesan per slide; kompleks dipecah (segmenting) | Mayer |
| Penanda bagian penting (signaling) | Mayer / Kosslyn |
| Jumlah slide ≈ 1 per 1–2 menit (sidang 10–15 mnt → 10–15 slide) | konvensi sidang |
| Font minimum terbaca | aturan 10/20/30 |
