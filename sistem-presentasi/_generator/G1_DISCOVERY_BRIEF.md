# G1 — Discovery BRIEF (Tahap 1) — wajib sebelum deck pertama

> Mematuhi `08`: setiap pertanyaan = paket rekomendasi+alternatif+konsekuensi+default. Isi `BRIEF.md` (template `T1`). Jangan mulai produksi selama field wajib kosong (fail-closed).

## Yang digali & rekomendasi default agent
1. **Tujuan pakai** — default: "alat presentasi [sidang/rapat/kelas]"; tanya occasion bila tak jelas. Konsekuensi: menentukan penekanan (sidang → temuan/kontribusi dulu).
2. **Audiens** — default dari tujuan (sidang → dosen penguji).
3. **Durasi & jumlah slide** — rekomendasi 10–15 slide utk 10–15 mnt (bukti: konvensi sidang); alternatif lebih pendek/panjang + trade-off.
4. **Sumber bahan** — dokumen pengguna (default) dan/atau riset internet. Catat jalur baca (Arab=visi).
5. **Tingkat anti-ngarang** — default `ringkas`; alternatif `ketat`/`ringkas+label` + konsekuensi.
6. **Mode gambar** — default utk sidang: M1+M2; M3 hanya konsep; M4 hanya bila perlu+gerbang (07).
7. **Preferensi penyajian** — bullet vs paragraf; default campuran (assertion + paragraf ringkas / bullet secukupnya).
8. **Gaya/aset** — bila tak punya, agent riset lalu tawarkan 2–3 palet dengan rekomendasi (08); default dinyatakan.
9. **Ketentuan institusi** — ada/tidak; bila ada → jalankan G3.
10. **Nama deck/slug** — agent usulkan di awal Tahap 1, pengguna pilih saat itu juga.

Semua keputusan + alasan + pemutus → `BRIEF.md` + Log Keputusan. Simpan **verbatim** perkataan pemilik (03).
