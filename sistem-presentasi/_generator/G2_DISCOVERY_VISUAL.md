# G2 — Discovery Visual (Tahap 3) — selalu wajib

> Mematuhi `08`. Hasil → `RENCANA_VISUAL.md` (+`OUTLINE.md` judul assertion per slide & jejak).

1. Bila pengguna **sudah punya gaya/aset** → warisi (lapisan B), cek kontras/keterbacaan.
2. Bila **belum** → agent **riset** (boleh internet) lalu tawarkan **2–3 paket lengkap** (palet, font, layout, mode gambar) masing-masing dengan rekomendasi+dasar+trade-off; pengguna memilih. Default dinyatakan di muka.
3. **Mode gambar per slide**: tentukan M0–M4 per slide dengan alasan; M2 utk slide berangka; M3 label "ilustrasi AI"; M4 lewat gerbang & approval per gambar.
4. **Geometri gambar** per slide (area, w, h) — aspek-safe (07.G-2).
5. Terapkan lantai desain (06): assertion judul, coherence, redundancy→notes, segmenting, signaling.
6. Tunjukkan **preview** ke pengguna sebagai putusan visual (G2), termasuk cek "gambar bebas teks" (07.G-1).
