# Start Di Sini — Pilot Catatan Belajar

Sistem ini memproses satu bahan belajar melalui siklus:

```text
Capture → Extract → Structure → Verify → Apply → Observe
```

Untuk memulai satu unit kerja:

1. Baca `SYSTEM_MANIFEST.md`.
2. Buat folder unit kerja di `unit-aktif/[id-unit]/`.
3. Salin `STATUS_TEMPLATE.md` menjadi `STATUS.md`.
4. Ikuti `WORKFLOW.md`.
5. Gunakan `OUTPUT_TEMPLATE.md` untuk hasil resmi.
6. Jalankan pemeriksaan di `QUALITY.md` sebelum output dipakai.

Jika sesi terputus, baca `STATUS.md` dan verifikasi output terakhir. Jangan menebak tahap terakhir.
