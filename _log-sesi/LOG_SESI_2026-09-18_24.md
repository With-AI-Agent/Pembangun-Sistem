## Giliran 20 — pemilik menegaskan maksud "link": ke BERKAS PROMPT, bukan ke PR

Pemilik bertanya satu kalimat: *"Apakah kamu paham bahwa yang aku maksud adalah link ke file prompt
perintah untuk sesi hakim dan reviewer/pemeriksa nya? Bukan hanya file PR nya?"* Jawabannya: koreksi itu
benar. T-46 mencetak path absolut + link PR + permalink head, tapi **tidak ada satu pun yang menuju teks

teman yang membuka sesi hakim juga tidak. Aturan giliran 19 terpenuhi secara huruf, tidak secara maksud.

**Yang dikerjakan.** `tools/review_prompt.py --umumkan`: prompt ditempel ke kanal PR sebagai **komentar
penulis** (judul menyebut `penulis`, isi dipagari backtick lebih panjang dari pagar di dalam prompt),
lalu permalink-nya dicetak `handoff_block()` sebagai baris **LINK KE PROMPT INI (tahan lama, bisa dibuka
siapa pun)**. Urutan di `main()` sengaja: komentar = prompt murni, berkas lokal = prompt + blok serah
terima yang memuat permalink-nya.

**Penjagaannya terukur (regresi RP13, FI 131 → 135 PASSED).** Risiko nyatanya kuorum palsu: prompt
memuat contoh judul verdict yang sengaja tidak dipagari. RP13 menguji badan komentar sungguhan **lintas
alat** dengan `slot_hakim()` milik `ambil_verdict.py` → harus BUKAN slot; menguji pagar terluar > run
terpanjang di dalam prompt dan muncul tepat 2×; **memutasi** judul (label `penulis` dibuang) → HARUS
terbaca sebagai slot, bukti pengamannya bukan hiasan; dan menguji fail-closed slug tak terbaca.
`umumkan_prompt()` sendiri fail-closed tiga lapis: slug tak terbaca → tidak menempel; POST gagal /
respons tak terbaca → tidak mencetak link; komentar tetap terbaca sebagai slot → **DIHAPUS lagi**.

**Kesalahan agent di giliran ini.** Uji RP13 versi pertama memakai `min(panjang pagar) >= 4` dan GAGAL:
prompt di dalamnya memuat baris penutup pagar 3 backtick yang juga murni backtick, jadi `min()`
menangkap pagar dalam. Yang salah ujinya, bukan alatnya; diganti menjadi perbandingan pagar terluar
terhadap run terdalam. Dicatat karena kelas kesalahan ini (asumsi tentang isi prompt) persis yang
menyebabkan RP9/RP10 dulu.
