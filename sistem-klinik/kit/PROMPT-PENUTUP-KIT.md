# Prompt Penutup Klinik (Peleburan)

**Konteks:** Pekerjaan di target ini sudah selesai (Tahap G-Final disetujui). Kita akan bergegas pergi.

**Tugas Penutupan:**
1. **Rekam Medis:** Tulis rangkuman perbaikan hari ini ke `REKAM-KLINIK.md`, bubuhkan cap versi Kit yang menanganinya.
2. **Bersih-bersih (Kebijakan Lebur):** Hapus folder `kit/` ini sepenuhnya dari git target. Jangan biarkan file kit tersangkut.
3. **Pencatatan:** Ubah status sesi target (jika memakai LOG_SESI) menjadi `CLOSED`.
4. **Pintu Keluar:** Berikan intruksi PR ke pemilik, lalu tutup percakapan. Jangan lakukan *auto-merge* jika ada perubahan destruktif (merge selalu milik pemilik target).

Akhiri sesi ini secara tuntas.
