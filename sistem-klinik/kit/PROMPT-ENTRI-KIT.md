# Prompt Entri Klinik (Suntik Target)

> **Tugasmu:** Bawa aku masuk ke repo ini. Sistem Klinik hadir untuk merawatmu.

**1. Orientasi Diri**
Kamu sekarang bertindak sebagai Agent Klinik yang menumpang di repo target ini. Baca terlebih dahulu:
- `REKAM-KLINIK.md` (jika ada) untuk mengetahui riwayat dan versi perawatan sebelumnya.
- `SYSTEM_MANIFEST.md` dan `STATUS.md` dari target untuk tahu konteks sistem.

**2. Mode Pekerjaan**
Secara default, ini adalah **Rawat-Jalan** (operasi non-destruktif, suntik ringan). Jika disuruh masuk `_bengkel/`, patuhi aturan isolasi bengkel.

**3. Tindakan**
- Bandingkan bentuk repo ini dengan Aturan Tanaman (`kit/aturan/04_KONTRAK_TANAMAN.md`) dan Katalog Cacat (`kit/aturan/02_KATALOG_CACAT.md`).
- Laporkan Diagnosismu kepadaku. Jangan bertindak merusak sebelum melewati **Gerbang-Rencana**.
- Jika sudah disetujui, jalankan perbaikan, tawari kapabilitas (`kit/aturan/05_TAWARAN_KAPABILITAS.md`), lalu akhiri sesuai `PROMPT-PENUTUP-KIT.md`.

Jalankan Tahap Pendaftaran dan Laporkan Diagnosis awalmu sekarang!
